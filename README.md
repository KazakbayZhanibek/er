# Kompas — сайт и панель управления

Испанская версия сайта кадровой компании: собственный найм и подбор сотрудников для других работодателей. Пользователь выбрал визуальное направление №3: песочный фон, терракота, крупная редакционная типографика и широкая фотография.

Уточнение заказчика: при собственном найме работодателем выступает «Компас». При подборе в другие компании условия зависят от этой компании и обсуждаются с кандидатом индивидуально. Значение формулировки об оформлении после испытательного срока ещё уточняется; на сайте срок оформления и тип договора не заявлены.

## Что реализовано

- Адаптивная главная страница, навигация и мобильное меню.
- Основной сценарий для соискателя: вводные видео сразу после первого экрана, поиск работы и бланк заявки. Для работодателей — компактный отдельный блок в самом низу страницы и ссылка в подвале.
- Отдельные бланки для соискателя и работодателя с проверкой полей, просмотром и редактированием данных.
- Общие заявки по всей Испании, требование знания испанского, индивидуальные условия и общение с менеджером через переводчика.
- Раздел о компании и два готовых вводных видео с управлением воспроизведением, встроенными испанскими субтитрами и текстом озвучки.
- Монограмма K, испанский интерфейс, часы работы 9:00–18:00 по Мадриду и согласованный срок связи 24 часа.
- Локальные шрифты, библиотека иконок Phosphor и оптимизированные WebP-изображения.
- Поддержка клавиатуры и уменьшения анимации.

По ответам заказчика от 2026-11-10 заявки должны поступать на email, но адрес будет предоставлен позже. Поэтому формы пока остаются бланками: данные не отправляются и не сохраняются. После проверки данных можно вернуться к редактированию или закрыть предпросмотр; ложного сообщения об отправке нет. Для соискателя обязательны имя, email и короткое сопроводительное письмо; телефон, город и область интереса необязательны. Работодатель указывает компанию и потребность в сотрудниках. Используются общие заявки без каталога вакансий. Испанский шаблон подтверждения для будущего подключения находится в `shared/application-messages.mjs`; сейчас он не отправляется. Реквизиты, адрес и контакты не выдуманы.

Видео: «Bienvenido a Kompas» — 40,1 с, «Tu primer día» — 44,6 с. Готовые MP4 и обложки включены в `public/media/`; отдельные проекты производства видео в этот репозиторий не входят и для запуска сайта не нужны. Видео не воспроизводятся автоматически и используют `preload="none"`. При запуске одного ролика другой останавливается.

## Запуск

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 4173 --strictPort
```

Сборка: `npm run build`. Статические файлы находятся в `dist/client`; локальный просмотр собранной версии — `npm run preview`. Сборка также подготавливает Worker для Sites.

## Управление текстами, блоками и заявками

`npm run build` отдельно собирает панель в `dist/admin`. После сборки `npm run admin` запускает локальный сервер на `http://127.0.0.1:4174`, панель доступна по `/admin/`. Она позволяет редактировать тексты, добавлять и переставлять текстовые блоки, экспортировать содержимое в JSON, просматривать существующие заявки и менять их статус/заметки. Приём новых заявок выключен до настройки почты; демонстрационные записи не создаются.

Пароль задаётся через `KOMPAS_ADMIN_PASSWORD` (не короче 16 символов). Для локального просмотра сервер может создать случайный пароль в `.kompas-data/local-admin-password`; значение не печатается в журнал. Не публикуйте эту папку. Данные сохраняются на диске, доступ к панели требует входа, конфликт параллельных правок отклоняется. Тексты и дополнительные блоки проходят проверку структуры и выводятся как обычный текст.

Сохранённые в панели изменения видны на сайте **этого же сервера**. Публичный GitHub Pages является отдельной статической публикацией: локальная панель его не обновляет. Для онлайн-доступа Ерасыла нужен выбранный сервер с HTTPS, постоянным диском, настроенным внешним адресом и персонально переданным доступом. Онлайн-панель и почта пока не развёрнуты. Редактирование исходного `src/content/site.json` и обычная публикация обновляют GitHub Pages; JSON из панели можно использовать при переносе контента.

Проверка сервера: `npm run test:admin`. Сервер и его настройки описаны также в `server/`.

## GitHub Pages

Предпросмотр: [kazakbayzhanibek.github.io/er/](https://kazakbayzhanibek.github.io/er/).

В `main` хранятся исходники. Pages должен публиковать ветку `gh-pages`, папку `/ (root)` — в неё помещается готовая сборка из `dist/client`. Исходный `index.html` из `main` напрямую публиковать нельзя: он требует сборки Vite.

После фиксации изменений и настройки доступа Git к репозиторию команда `npm run deploy:pages` собирает сайт и отправляет результат в `gh-pages`. Она использует отдельный временный индекс Git, сохраняет историю публикаций и не переключает рабочую ветку. Публикация не подключает отправку или хранение заявок. Пути к ресурсам относительные, поэтому сайт работает и в корне, и по адресу `/er/`.

## Проверки и материалы

- Проверки сборки и упаковки: `npm run build` и `npm run test:sites`. Проверка 2026-11-10: обе сборки, четыре теста упаковки и девять тестов сервера прошли.
- В браузере проверены формы, редактирование данных, закрытие с клавиатуры, воспроизведение обоих видео и отображение на ширине 320, 768 и 1440 пикселей. Внутренние рабочие заметки и снимки проверки в репозиторий не включены.
- `public/images/ASSETS.md` — промпты и происхождение изображений. PNG — исходники; WebP — версии для сайта.
- `public/media/ASSETS.md` — происхождение готовых видео и обложек.
- Палитра: `#F3E8D7`, `#332923`, `#A84631`, `#FBF8F2`.
- [Newsreader](https://fonts.google.com/specimen/Newsreader) и [Manrope](https://fonts.google.com/specimen/Manrope) поставляются локально через Fontsource.
- [Phosphor React](https://github.com/phosphor-icons/react) используется для стандартных интерфейсных иконок.

## Для рабочего запуска

Остались адрес получателя и настройка почтового отправителя, домен, сервер для онлайн-панели, доступ Ерасыла и согласованные тексты об обработке данных с реальными данными компании. После подключения приёма нужно проверить доставку заявки и испанского подтверждения, убрать демонстрационные сообщения и согласовать окончательный запуск. Бренд Kompas, испанский язык, вся Испания и формат общих заявок уже подтверждены; каталог вакансий и публикация деталей договора сейчас не нужны.
