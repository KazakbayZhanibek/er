# Kompas — прототип сайта

Испанская версия сайта кадровой компании: собственный найм и подбор сотрудников для других работодателей. Пользователь выбрал визуальное направление №3: песочный фон, терракота, крупная редакционная типографика и широкая фотография.

Уточнение заказчика: при собственном найме работодателем выступает «Компас». При подборе в другие компании условия зависят от этой компании и обсуждаются с кандидатом индивидуально. Значение формулировки об оформлении после испытательного срока ещё уточняется; на сайте срок оформления и тип договора не заявлены.

## Что реализовано

- Адаптивная главная страница, навигация и мобильное меню.
- Раздельные пути соискателя и работодателя.
- Отдельные бланки для соискателя и работодателя с проверкой полей, просмотром и редактированием данных.
- Раздел о компании и два готовых вводных видео с управлением воспроизведением, встроенными испанскими субтитрами и текстом озвучки.
- Локальные шрифты, библиотека иконок Phosphor и оптимизированные WebP-изображения.
- Поддержка клавиатуры и уменьшения анимации.

По решению пользователя от 2026-10-26 формы пока остаются бланками: данные не отправляются и не сохраняются. После проверки данных можно вернуться к редактированию или закрыть предпросмотр; ложного сообщения об отправке нет. Телефон и город необязательны. Соискатель может указать область интереса и краткое сообщение; работодатель — компанию и потребность в сотрудниках. Реальные вакансии пока не добавлены. Название латиницей, логотип и фотографии — концепция до подтверждения заказчиком. Контакты, показатели компании и условия трудоустройства не выдуманы.

Видео: «Bienvenido a Kompas» — 40,1 с, «Tu primer día» — 44,6 с. Готовые MP4 и обложки включены в `public/media/`; отдельные проекты производства видео в этот репозиторий не входят и для запуска сайта не нужны. Видео не воспроизводятся автоматически и используют `preload="none"`. При запуске одного ролика другой останавливается.

## Запуск

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 4173 --strictPort
```

Сборка: `npm run build`. Статические файлы находятся в `dist/client`; локальный просмотр собранной версии — `npm run preview`. Сборка также подготавливает Worker для Sites.

## GitHub Pages

Предпросмотр: [kazakbayzhanibek.github.io/er/](https://kazakbayzhanibek.github.io/er/).

В `main` хранятся исходники. Pages должен публиковать ветку `gh-pages`, папку `/ (root)` — в неё помещается готовая сборка из `dist/client`. Исходный `index.html` из `main` напрямую публиковать нельзя: он требует сборки Vite.

После фиксации изменений и настройки доступа Git к репозиторию команда `npm run deploy:pages` собирает сайт и отправляет результат в `gh-pages`. Она использует отдельный временный индекс Git, сохраняет историю публикаций и не переключает рабочую ветку. Публикация не подключает отправку или хранение заявок. Пути к ресурсам относительные, поэтому сайт работает и в корне, и по адресу `/er/`.

## Проверки и материалы

- Проверки сборки и упаковки: `npm run build` и `npm run test:sites`. При последней локальной проверке 2026-10-26 сборка и все четыре теста прошли.
- В браузере проверены формы, редактирование данных, закрытие с клавиатуры, воспроизведение обоих видео и отображение на ширине 320, 768 и 1440 пикселей. Внутренние рабочие заметки и снимки проверки в репозиторий не включены.
- `public/images/ASSETS.md` — промпты и происхождение изображений. PNG — исходники; WebP — версии для сайта.
- `public/media/ASSETS.md` — происхождение готовых видео и обложек.
- Палитра: `#F3E8D7`, `#332923`, `#A84631`, `#FBF8F2`.
- [Newsreader](https://fonts.google.com/specimen/Newsreader) и [Manrope](https://fonts.google.com/specimen/Manrope) поставляются локально через Fontsource.
- [Phosphor React](https://github.com/phosphor-icons/react) используется для стандартных интерфейсных иконок.

## Для рабочего запуска

Нужны подтверждённые бренд и домен, профессии и реальные вакансии, детали договоров и оформления, контакты, языки и юридические тексты. Подключение доставки и хранения заявок отложено пользователем на следующий этап; канал приёма ещё не выбран. Перед запуском следует добавить реальные данные, согласовать содержание видео, подключить доставку заявок, заменить демонстрационные сообщения, проверить обработку данных и согласовать публикацию.
